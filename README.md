# Crownfield Eye Hospital – MySQL Database Project
 
## Project Overview

This project involves designing and developing a relational database for Crownfield Eye Hospital using MySQL.
 
The database aims to improve the management of patient records, clinical appointments, diagnoses, prescriptions and healthcare information.
 
## Project Objectives

- Design a relational database using MySQL.

- Apply database normalisation from UNF to 3NF.

- Develop an Entity Relationship Diagram (ERD).

- Establish relationships using primary and foreign keys.

- Implement SQL queries for data management and retrieval.

- Explore database security through role-based access control.
 
## Technologies Used

- MySQL

- MySQL Workbench

- SQL

- Entity Relationship Diagrams (ERD)
